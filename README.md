# Portofolio Muhammad Rizki Zain

Website profil pribadi Muhammad Rizki Zain, siswa Rekayasa Perangkat Lunak di SMKN 1 Jakarta. Situs ini menampilkan profil, keterampilan, pengalaman organisasi dan pelatihan, proyek IoT, serta informasi kontak.

## Fitur

- Navigasi ke bagian Tentang, Pengalaman, Proyek, dan Kontak.
- Tampilan responsif dengan menu navigasi untuk layar kecil.
- Animasi saat bagian halaman muncul ketika digulir.
- Bagian profil, daftar keterampilan, pengalaman, dan proyek pilihan.
- Tautan kontak melalui email, GitHub, dan Instagram.

## Teknologi

- React 19
- Vite 8
- CSS

## Menjalankan secara lokal

Pastikan Node.js dan npm sudah terpasang, kemudian jalankan:

```bash
npm install
npm run dev
```

Vite akan menampilkan alamat lokal di terminal (biasanya `http://localhost:5173`). Buka alamat tersebut di browser.

## Perintah yang tersedia

| Perintah | Keterangan |
| --- | --- |
| `npm run dev` | Menjalankan server pengembangan. |
| `npm run build` | Membuat hasil build produksi di folder `dist`. |
| `npm run preview` | Meninjau hasil build produksi secara lokal. |
